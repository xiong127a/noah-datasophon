# MinIO 组件介绍

## MinIO 是什么

MinIO 是一个高性能的分布式对象存储系统，它以开源方式提供了企业级的对象存储服务。MinIO 完全兼容 Amazon S3 云存储服务接口，可以作为云存储的替代方案用于存储非结构化数据，如照片、视频、日志文件、备份和容器镜像等。

MinIO 采用 Go 语言开发，具有高性能、易于部署和使用的特点。它可以在各种基础设施上运行，包括裸机、虚拟机、容器和公有云，为现代应用程序和机器学习工作负载提供可靠的数据存储基础。
