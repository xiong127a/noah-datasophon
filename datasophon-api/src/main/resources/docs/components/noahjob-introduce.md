# NOAHJOB 组件介绍

## 什么是NOAHJOB

NOAHJOB是北京中兵数科公司基于Apache DolphinScheduler深度定制改造的企业级工作流任务调度平台。它继承了DolphinScheduler的分布式、可视化DAG工作流设计理念，并针对军工行业、企业级应用场景进行了深度优化和功能扩展，提供了更加安全、稳定、高效的任务调度解决方案。

作为专为国防军工、政府和大型企业设计的工作流调度系统，NOAHJOB不仅具备强大的数据处理和任务编排能力，还特别关注安全合规、系统稳定性和用户友好性，满足关键业务领域的严格需求。

## 核心功能特性

### 继承自DolphinScheduler的基础功能

* **可视化DAG工作流**：通过拖拽式操作定义复杂的工作流程
* **丰富的任务类型**：支持Shell、SQL、Python、Spark等多种任务类型
* **分布式架构**：多Master和多Worker的高可用设计
* **强大的调度能力**：支持Cron表达式、依赖触发等多种调度方式
* **资源管理**：租户隔离、Worker分组等资源隔离机制

### 军工级安全增强

* **安全合规认证**：符合军工行业安全标准和认证要求
* **多级权限控制**：基于RBAC模型的细粒度权限管理
* **安全审计**：全面的操作审计和日志追踪能力
* **数据加密传输**：关键数据和通信内容的加密保护
* **数据脱敏**：敏感信息自动脱敏处理
* **安全漏洞修补**：针对开源版本的安全漏洞进行全面修补

### 增强的稳定性和可靠性

* **增强的容错机制**：更完善的节点故障恢复和任务重试策略
* **智能负载均衡**：基于节点资源使用情况的智能任务分配
* **优化的资源管理**：防止资源过度分配和任务竞争
* **全局状态监控**：更全面的系统运行状态监控和预警
* **定向恢复能力**：支持指定节点或任务的精确恢复

### 军工场景定制功能

* **任务优先级控制**：支持任务紧急程度分级和优先调度
* **安全隔离执行**：支持在完全隔离环境中执行敏感任务
* **离线环境支持**：适应完全离线的网络环境要求
* **大规模集群支持**：优化大规模节点管理和监控
* **强化的告警机制**：多渠道、多级别的告警通知
* **应急指令通道**：支持紧急任务插队和系统熔断机制

### 用户体验优化

* **简化的操作界面**：更符合国内用户习惯的交互设计
* **中文文档和帮助**：完善的中文用户手册和上下文帮助
* **统一的仪表盘**：整合关键指标的监控仪表盘
* **改进的日志查看**：更便捷的日志检索和分析工具
* **自定义报表**：灵活的任务执行报表和统计分析
* **移动端支持**：支持移动设备监控和应急操作

## NOAHJOB架构

NOAHJOB基于DolphinScheduler的架构进行了优化和扩展，主要组件包括：

### 核心组件

#### MasterServer增强版

在DolphinScheduler基础上增强的主控服务器，负责工作流解析、任务分发和调度决策。

**增强功能**：
* **智能调度引擎**：基于多维度的任务优先级排序算法
* **主备无缝切换**：零数据丢失的Master故障转移
* **分布式锁优化**：减少锁竞争，提高并发性能
* **任务预测系统**：根据历史数据预测任务执行情况
* **资源配额管理**：支持租户和项目级别的资源配额

#### WorkerServer增强版

负责任务执行的工作节点，在DolphinScheduler基础上进行了优化。

**增强功能**：
* **任务隔离容器**：基于容器技术的任务执行环境隔离
* **资源动态调配**：根据任务特性动态分配计算资源
* **本地缓存优化**：减少远程调用，提高执行效率
* **黑名单机制**：自动识别问题节点并进行隔离
* **预热机制**：支持执行环境预热，减少任务启动时间

#### ApiServer增强版

提供统一的API服务，支持各类客户端接入。

**增强功能**：
* **接口安全加固**：增强的接口认证和访问控制
* **限流保护**：基于用户和IP的智能限流
* **国产中间件适配**：支持国产数据库和中间件
* **多协议支持**：兼容REST、gRPC等多种协议
* **API版本管理**：支持多版本API共存和平滑升级

#### 安全中心（新增组件）

NOAHJOB新增的安全控制中心，负责全系统的安全策略管理。

**主要功能**：
* **统一认证中心**：集中的用户认证和单点登录
* **动态授权管理**：基于角色和标签的动态权限控制
* **操作审计**：全面的用户操作记录和审计
* **安全合规检查**：定期的安全合规自检
* **数据权限管理**：细粒度的数据访问控制

#### 高可用管控中心（新增组件）

负责系统整体高可用保障的管控组件。

**主要功能**：
* **集群健康监控**：全方位监控系统各组件健康状态
* **故障自动恢复**：检测并自动恢复故障节点
* **负载感知调度**：基于集群负载状况的智能调度
* **灾备切换**：支持跨区域的灾备部署和切换
* **容量规划**：系统资源使用分析和扩容建议

### 存储架构优化

* **多级存储策略**：热数据和冷数据分层存储
* **国产数据库适配**：支持多种国产商业和开源数据库
* **元数据高可用**：元数据的多副本一致性保障
* **存储性能优化**：针对大规模工作流的存储结构优化
* **历史数据管理**：自动化的历史数据归档和清理

### 网络架构增强

* **数据传输加密**：组件间通信内容加密
* **网络隔离支持**：适应多网隔离的特殊环境
* **带宽优化**：减少网络数据传输量
* **连接池管理**：优化网络连接资源使用
* **通信协议优化**：更高效的组件间通信协议
