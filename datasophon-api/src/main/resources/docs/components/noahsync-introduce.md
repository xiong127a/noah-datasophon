# NOAHSYNC 组件介绍

## 什么是NOAHSYNC

NOAHSYNC是北京中兵数科公司基于Apache SeaTunnel（原名Waterdrop）深度定制改造的企业级数据同步与集成平台。它继承了SeaTunnel简单易用、高性能的特点，并针对军工行业、政府和大型企业的特殊需求进行了全面优化和功能扩展，提供了更加安全、稳定、高效的数据集成解决方案。

作为专为国防军工和关键业务领域设计的数据同步工具，NOAHSYNC不仅具备强大的数据处理和转换能力，还特别关注数据安全、传输可靠性、系统稳定性和国产化支持，满足高安全等级环境下的严格要求。

## NOAHSYNC架构

NOAHSYNC基于SeaTunnel的架构进行了优化和扩展，主要组件包括：

### 核心架构图

```
+------------------------------------------+
|            NOAHSYNC平台管控层              |
|    (配置管理|监控|安全控制|资源管理|调度)    |
+------------------------------------------+
|                                          |
|  +-------------+      +---------------+  |
|  |   Sources   | ---> | Transformations| |
|  +-------------+      +---------------+  |
|                            |             |
|                            v             |
|                       +--------+         |
|                       |  Sinks |         |
|                       +--------+         |
|                                          |
+------------------------------------------+
|             增强引擎适配层                 |
|  (Spark / Flink / 国产引擎/ 独立引擎)      |
+------------------------------------------+
|             安全通信与存储层               |
+------------------------------------------+
```

### 核心组件

#### 平台管控层

* **配置中心**：管理连接器配置、任务定义和系统参数
* **监控中心**：实时监控任务执行状态和性能指标
* **安全控制中心**：集中管理用户认证、授权和安全策略
* **资源管理器**：统一管理和分配计算资源
* **调度器**：智能规划和调度数据同步任务

#### 数据处理核心

* **增强连接器集**：
  * **源连接器（Source）**：从各类数据源读取数据，支持增量捕获
  * **转换器（Transformation）**：执行数据转换、清洗和处理
  * **目标连接器（Sink）**：将处理后数据写入目标系统
* **流程控制器**：管理数据流程的执行和状态转换
* **元数据管理器**：管理连接器元数据和数据结构定义

#### 增强引擎适配层

* **Spark引擎适配器**：优化的Apache Spark执行适配
* **Flink引擎适配器**：优化的Apache Flink执行适配
* **国产引擎适配器**：支持国产计算引擎的适配器
* **独立引擎**：内置轻量级执行引擎，适用于小规模场景

#### 安全通信与存储层

* **安全通信模块**：加密的组件间通信机制
* **安全存储模块**：敏感配置和中间数据的安全存储
* **密钥管理**：加密密钥的生成、分发和管理
* **安全审计日志**：详细记录系统操作和数据访问

### 工作流程

1. **配置定义**：用户通过配置中心定义数据同步任务
2. **资源分配**：调度器为任务分配合适的计算资源
3. **任务提交**：任务提交到选定的执行引擎
4. **数据读取**：源连接器从数据源读取数据
5. **数据转换**：转换器执行数据处理和转换逻辑
6. **数据写入**：目标连接器将结果写入目标系统
7. **监控反馈**：全程监控任务执行状态和数据质量
8. **任务完成**：任务完成后生成详细的执行报告
