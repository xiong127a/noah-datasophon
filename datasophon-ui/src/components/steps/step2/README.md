# 主机检查模块

本模块实现了主机检查功能，包括主机校验、状态监控、修复等功能。

## 架构设计

采用模块化设计，将代码拆分为多个组件和服务，提高代码可维护性和复用性。

### 组件结构

- **index.vue**: 主组件，整合所有功能
- **HostCheckItems.vue**: 主机检查项组件，展示每个主机的检查项列表
- **FixConfirmModal.vue**: 修复确认对话框
- **HostnameEditModal.vue**: 主机名编辑对话框
- **QueueStatusIndicator.vue**: 队列状态指示器

### 服务和工具

- **HostCheckService.js**: API服务层，封装所有HTTP请求
- **StatusCalculator.js**: 状态计算工具，处理状态相关的逻辑
- **HostTableColumns.js**: 表格列定义
- **HostCheckConstants.js**: 常量定义

### 样式

- **HostCheck.less**: 统一的样式文件

## 功能特点

1. **主机检查**: 支持批量检查主机环境
2. **实时状态监控**: 通过轮询获取最新检查状态
3. **检查项管理**: 支持重试、修复、跳过等操作
4. **主机管理**: 支持修改主机名等操作
5. **日志查看**: 支持查看检查项的详细日志

## 使用方法

1. 在页面中引入主组件:

```vue
<host-check clusterId="your-cluster-id" />
```

2. 组件会自动加载并开始检查
